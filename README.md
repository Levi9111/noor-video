A broadcast-grade, programmatic lyrical video and motion picture visualizer for the song **"নূরের পথ / راه نور (The Path of Light)"**. 

Built with **Remotion (React Video)** and **Web Audio / Canvas API**, this project transforms a Sufi romantic duet into a poetic visual journey — featuring focus-pull kinetic typography, living candlelight illumination, floating golden embers, and art-house bilingual subtitles.

---

## 📽️ Visual & Cinematic Direction

- **Zero "Website" Chrome**: No navigation bars, widgets, or mechanical badges. Every frame is treated as a 35mm film shot.
- **2.39:1 Anamorphic Framing**: Top and bottom cinematic letterbox bars give the composition a widescreen feature film aesthetic.
- **Kinetic Focus-Pull Typography**: Each poetic phrase arrives with a camera focus pull (`blur(12px) → blur(0px)`) and continuous forward dolly drift (`scale(0.97) → scale(1.03)`).
- **Living Candlelight / Noor Flame**: The central earthen clay oil lamp (*নূরের বাতি*) levitates with dynamic organic flame flickers and heat distortion.
- **Deterministic Golden Embers**: 60 floating golden embers and soft rose-amber bokeh circles drift upward like prayer smoke, calculated mathematically for 100% stutter-free video rendering.
- **Bilingual Dual-Script Typography**:
  - **Bengali Verses (Male Vocal)**: High-contrast romantic serif (*Noto Serif Bengali*, *Hind Siliguri*) with warm amber luminescence.
  - **Persian Verses (Female Vocal)**: Classical Nastaliq/Naskh Arabic calligraphy (*Amiri*, *Scheherazade New*) rendered RTL with soft rose-gold radiance.
  - **Art-House Film Subtitles**: Prominent, highly legible Bengali translations (`বাংলা অর্থ: ...`) rendered in glowing golden pills below the Persian verses.

## 🚀 How to Run & Preview

### Option 1: Remotion Studio (Visual Timeline & Frame Scrubber)

Remotion Studio provides a professional video timeline player right in your browser:

```bash
cd noor-video
npm run dev
```

- Open **[http://localhost:3333](http://localhost:3333)** (or port 3000).
- Scrub through all **6,563 frames** with millisecond accuracy.
- Watch the kinetic transitions, camera drift, and audio synchronization live.

### Option 2: Render to High-Quality 1080p MP4 Video File

To render the complete video composition directly to an `.mp4` file using Remotion's CLI:

```bash
cd noor-video
npx remotion render NoorLyricVideo out/Noor_Cinematic_Video.mp4
```

*Note: If your system uses a custom browser binary like Firefox, pass `--browser-executable=/usr/bin/firefox`.*

### Option 3: Clean Cinema Web Player (with 1-Click Video Exporter)

You can also run or open the pure web video player in the root directory:

```bash
# In the root workspace:
python3 -m http.server 8080
```

- Open **`http://localhost:8080/index.html`** in any browser.
- **Controls auto-hide** after 2 seconds of playback (like YouTube/Netflix), leaving 100% clean video on screen.
- Press **Space** to play/pause, **F** for Fullscreen.
- Click **"Export Video (MP4)"** on the bottom-right HUD to record and download a clean 1080p video file instantly!
